# Ghi chú về lệnh Git

1. git init: Khởi tạo một kho Git mới.

2. git status: Kiểm tra trạng thái của các tệp trong kho Git.

3. git add: Đưa thay đổi từ Working Directory vào Staging Area.

4. git commit: Lưu các thay đổi trong Staging Area vào Repository.

5. git push: Đẩy các commit từ Repository trên máy lên Repository trên GitHub.
